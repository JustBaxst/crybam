# PLAN.md — План проекта Crybam

## 🎯 Философия проекта
Личный дневник для души, а не сухой трекер. Модульная платформа-конструктор: от «розового с блёстками» до «строгого чёрного блокнота». Приватность по желанию. Каждый находит своё.
- Эмоции, цитаты, «особое место в сердце»
- Портрет зрителя, который строится ИИ из отзывов
- Приватность по желанию
- Личные номинации («моя лучшая романтика 2024»)
- Сообщество тихих людей, которые любят дорамы

## 🏗 Архитектура
- **Публичная часть**: /dramas, /library, /people, /characters, /me, /nominations, /heart, /stats, /news, /calendar, /about, /reviews
- **Админка**: /admin/* — редактирование базы
- **Роли**: user, contributor, moderator, admin (реальная авторизация — Этап 16)
