# PAGE_RECIPES.md: Рецепты страниц

## Рецепт 1: Bento-страница сущности

(Используется: `/dramas/[id]`, `/people/[id]`, `/characters/[id]`)

**Структура:**

1. **Хлебные крошки:** `text-sm text-muted mb-6`.
2. **Заголовок:** `text-[clamp(1.75rem,3vw,2.5rem)] font-bold` + альтернативные имена.
3. **Hero-сетка (`grid grid-cols-4 gap-6 mb-10`):**
   - **Левая (col-span-1):** Постер `aspect-[2/3]` + кнопка действия (`StatusDropdown` для дорам, `FavoriteActorButton` для актеров).
   - **Центр (col-span-2):** Bento-блок «О ...» (2 колонки фактов).
   - **Правая (col-span-1):** Bento-блок «Действия» (для актеров — `SocialLinks` с максимум 5 видимыми иконками и поповером `+N`).
4. **Широкий блок:** Синопсис / Биография (Bento, с разделителем под заголовком).
5. **Табы:** Radix UI, стилизованные под дизайн.

**Компоненты:** `Tabs`, `RatingWidget`, `CardStatusToolbar`, `CryTagSelector`, `CryTagStats`, `TagsPopover`, `MoreItemsPopover`, `SoundtrackPlayer`, `AlternativeTitles`, `StatusDropdown`, `FavoriteActorButton`.

### 💡 Админская версия Bento-страницы

Для админки (`/admin/*`) используется аналогичная Bento-сетка (Постер слева, Факты справа), но с отличиями:

- Данные выводятся в режиме **read-only** (только для чтения).
- В шапке страницы расположены кнопки: «Редактировать» (открывает модалку с формой) и «Удалить».
- Рядом с каждым блоком (Жанры, Темы, Настроения) находится своя кнопка «Редактировать» (`GenresEditButton`, `ThemesEditButton` и т.д.).
- Для пустых полей выводится серая заглушка (`—` или `text-muted/50 italic`), чтобы админ видел, что поле существует и его нужно заполнить.

## Рецепт 2: Каталог с фильтрами

(Используется: `/dramas`, `/people`, `/characters`)

**Структура:**

1. **Заголовок** + счетчик.
2. **Блок «Навигация»** (`bg-surface/20 rounded-2xl p-6`):
   - Заголовок с иконкой `Compass`.
   - Поиск (`AdminSearchBar`).
   - Тулбар фильтров: `CatalogToolbar` (дорамы), `PeopleToolbar` (актеры), `CharactersToolbar` (персонажи). Внутри — `SearchableSelect` для списков с поиском.
   - Активные фильтры (плашки с крестиком и функцией `buildClearUrl`).
3. **Сетка карточек:** `CatalogCard` (с рейтингом Crybam, hover-оверлеем и `CardStatusToolbar`).

## Рецепт 3: Дашборд (Избранные актеры / персонажи)

1. **Заголовок** с короной.
2. **Сетка статистики** (`grid-cols-2 md:grid-cols-3 lg:grid-cols-6`). 6 Bento-блоков с цифрами и иконками.
3. **Сетка карточек** (избранные) — используем `PeopleCard` или `CharacterCard` с `hideHover={true}`, `showFavoritePills={false}` (и `note`, если есть).
4. **Горизонтальные карусели** (Топы) — используем те же карточки с `rank` и `footerText` внутри обёртки `w-40 shrink-0`.
   ⚠️ Не писать кастомную вёрстку карточек внутри страницы — только пропсы существующих компонентов.

## Рецепт 4: Форма создания/редактирования

(Используется: `NewDramaForm`, `PersonForm`, `EditEntryForm`, `EditDramaForm`)

**Структура:**

1. **Обертка:** `rounded-2xl border border-border bg-surface p-6 space-y-8`.
2. **Секции:** `FormSection` (иконка + заголовок + описание + поля).
3. **Поля:** использовать `components/ui/form-elements.tsx` (FormInput, FormSelect, FormTextarea) — после его создания.
4. **Импорт:** кнопка `TvmazeImportModal` (предпросмотр с чекбоксами, исключая название и синопсис на английском).
5. **Кнопка:** `Button` с `type="submit"` + `isPending` для дизейбла.
6. **Ошибки:** красный блок с `error` и кнопкой «Открыть её →» (для дублей `existingId`).
7. **Планируется:** Sticky-панель справа со статусом заполнения (чек-лист).

## Рецепт 5: Таб «Галерея»

1. Bento-обёртка.
2. Заголовок с иконкой `Image`.
3. Секции: «Трейлеры», «Кадры», «Постеры».
4. Пустое состояние — dashed-блок.

## Рецепт 6: Страница избранного (Актеры / Персонажи)

**Структура:**

1. **Хлебные крошки:** `text-sm text-muted mb-6` (Главная → Любимые …).
2. **Заголовок:** иконка `Crown` + название, подзаголовок с описанием.
3. **Bento-статистика:** 4–6 плашек (`bg-surface/20 p-4 rounded-2xl border border-border/50`) с иконками из `lucide-react`.  
   _Для актёров:_ Всего, Средний возраст, Всего ролей, Топ-агентство, Топ-MBTI, Топ-Зодиак.  
   _Для персонажей:_ Всего, Топ-дорама, Топ-актёр, Топ-важность.
4. **Секция «Твои избранные»:** сетка карточек (`grid-cols-2 md:grid-cols-3 lg:grid-cols-4`).  
   Карточки — через `PeopleCard` / `CharacterCard` с `hideHover={true}`, `showFavoritePills={false}`, при наличии — `note`.
   Пустое состояние — dashed-блок с кнопкой «Перейти в каталог».
5. **Топы (горизонтальные карусели):**
   - «Топ среди фанатов» (глобальный).
   - «Топ по ролям» (для актёров) или «Топ по дорамам» (для персонажей).  
     Внутри — те же карточки с `rank` и `footerText`, обёрнутые в `w-40 shrink-0`.

**Данные (Prisma):**

- `userFavoriteActor.findMany` или `userFavoriteCharacter.findMany` с `include` нужных полей.
- Для глобального топа — `person.findMany` / `character.findMany` с `favoriteBy: { some: {} }` и `orderBy: { favoriteBy: { _count: "desc" } }`.

**Правила:**

- ❌ Не дублировать карточки — только пропсы.
- ✅ Проверять `PROJECT_INDEX.md` и `DESIGN_SYSTEM.md` перед созданием.
